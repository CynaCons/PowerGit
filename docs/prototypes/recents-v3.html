What every proposal does

Owner, 2026-10-12: "The UI to select the recent repositories is really not good … When the user has gone to the extent that he has selected a project, he wants to read the history of that project."
  • One click opens. A single click (or Enter) opens the repository straight into its history. No select-then-double-click, no preview to get past.
  • Open folder… lands in the history, never back in a list (already fixed in the tree, a6be167e9).
  • The task is the name. Most recents are checkouts of two projects, one per task branch, so rows are grouped by project and lead with the branch.
  • Keyboard first: Ctrl+R opens the picker anywhere, type to filter, ↑↓ and Enter. Pin with the star; remove with Del.
Names are invented (atlas-…, orion-…) to follow the pattern without publishing real ones.

A · Switcher — the repository name in the title strip opens a dropdown over the graph

You never leave the history to change repository. Click the name (or Ctrl+R), type a few letters of the task, press Enter. The graph behind stays put until the new one arrives.

Good for

  • Needs a welcome screen when nothing is open — D or the same list full-width

B · Tabs — the repositories you work in stay open as tabs

Like a browser: each repository you open becomes a tab and keeps its scroll and selection. "+" opens the same filtered list as A, and Open folder… adds a tab. Close a tab with its ×; the list of recents is unchanged.

  • Biggest change of the four; tab bar takes 40 px of height

C · In the rail — a Repositories list that is always there

The left pane gets a Repositories section above the branch tree (or as a tab of it): the current one highlighted, the rest one click away, grouped by project. Like Fork's sidebar or SourceTree's bookmarks.

D · Welcome — a plain page when nothing is open, A everywhere else

Only at start (or after closing a repository): one column, the actions on top, then the recent ones as rows you click once. Once a repository is open the title-strip switcher of A takes over; this page never sits between you and a history again.
