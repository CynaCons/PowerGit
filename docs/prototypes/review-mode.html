Review mode in the Diff panel

Clickable draft. Turn review mode on with the round button at the bottom of the file list, next to the tree toggle. Every changed or added line starts unreviewed; each press of Space (or a click) cycles it: unreviewed → ok → rejected → unreviewed. x toggles rejected directly.

↑ ↓ or k j move a line, gg / G top and bottom, n next unreviewed, Enter next file, Shift+Enter previous file. / opens a command line on the current line: /comment why this is wrong, /ok, /reject, /clear. In the artifact viewer the first click only focuses the page; click again.

    What this drafts, and what comes after
    
  
      
    
    1. The review lives in one file per reviewed commit, .powergit/reviews/<commit>.json (the Working directory review is keyed by the HEAD it sits on). Each changed line is keyed by file, side and line number with its state; comments sit beside them. The Review file button shows it live; here it is kept in the browser instead of on disk.
      2. 
    
    2. Context lines are never part of the count. Only + and − lines are, because that is what a reviewer is accountable for. Rejected counts as reviewed, and is listed separately.
      3. 
    
    3. Finish review hands that file to the AI reviewer, later over MCP: the rejected lines and the comments are the brief, the ok lines are the context it may skip.
