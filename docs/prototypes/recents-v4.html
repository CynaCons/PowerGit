Built around worktrees

Owner, 2026-10-13: "I would prefer a design where it takes in consideration the names and the paths … and very importantly would be better able to handle work trees … I would like to more easily find my work trees … or maybe we can try something that would be based on cards."
  • Worktrees belong to their repository. PowerGit reads each folder's .git link to find its main repository and groups them. The main checkout is marked main.
  • All of a repository's worktrees are listed, not only the ones opened before: git worktree list finds the rest. They are shown dimmed as never opened.
  • Name, branch and path are all on screen, and the filter matches any of them.
  • One click opens the worktree's history. Open folder… does the same, and adds the folder's siblings to the list.
Names and paths are invented, following the pattern of two big repositories with many task worktrees.

E · Repository cards — one card per repository, its worktrees inside

The repositories you work in, as cards. Each one lists its worktrees: folder, branch, where it lives, its state. You find a worktree by first finding its repository, which is how you think of it anyway.

Good for

Costs
  • A repository with 15 worktrees makes a tall card ("+ 9 more" folds it)
  • Standalone repositories get small cards

F · Worktree cards — every worktree a card, in sections by repository

The worktree is the thing you open, so it gets the card: its branch large (that is the task), the folder and path under it, its state and its last commit. Sections keep each repository's worktrees together; the coloured edge is the repository.

  • Filtering narrows the grid without losing the sections
Costs
  • Fewer worktrees fit on screen than in a list (about 12 at 1600 px)
  • Paths are shortened in the middle on narrow cards

G · Tree with paths — repositories and their worktrees in one sortable list

Dense and explicit, like a file explorer: each repository is a row that folds, its worktrees indented under it, with the path in its own column. Sort by any column; the filter marks what matched, path included.
